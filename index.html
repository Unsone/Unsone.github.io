About Me

I am an undergraduate student in the School of Computer Science and Engineering at Beihang University, studying Virtual Reality Technology.

My interests lie in diffusion models, language model optimization, and AI agents. My current work explores how signal-to-noise ratio can guide adaptive timestep selection for diffusion sampling, alongside controlled experiments on the components of Adam in language model training.

I also enjoy building systems that connect algorithms with practical applications, from visual detection and tracking to interactive virtual experiments. Please feel free to email me to discuss research or projects.

Projects

  • SNR-Guided Adaptive Denoising

    Diffusion models · Ongoing research

    Investigating how an image's estimated signal-to-noise ratio can determine the starting timestep for DDIM sampling. The project compares classical blind estimators with a learned regressor, studies their failure modes at high noise levels, and evaluates the tradeoff between denoising steps and reconstruction quality on CIFAR-10.

    Code & experiments

  • Understanding Adam in Language Model Training

    Optimization · Controlled experiments

    A controlled study of momentum and adaptive preconditioning in a decoder-only Transformer trained on WikiText-103. A shared optimizer framework compares SGD, momentum, RMS, and Adam while holding the training setup consistent, with analysis of learning curves, token-frequency effects, and parameter-level update statistics.

    Code & experiments

  • Ledger-Agent

    AI agents · Local task automation

    A local assistant that turns natural-language requests into structured plans and executes them through tools for files, shell commands, Git, and web search. I built the planning and execution loop with tool-level safety rules, execution retries, result verification, and retrieval-based memory to support tasks across sessions.

    Code

  • Laser Mosquito Control: Visual Detection & Tracking

    Computer vision · Embedded inference

    A visual perception system for an intelligent laser mosquito-control device. I was responsible for mosquito detection and trajectory tracking, including training the detection model and optimizing inference speed on the embedded platform.

  • MRLab: Interactive Virtual Chemistry Lab

    Unity · Educational simulation · PC prototype

    An interactive Unity simulation of the elephant toothpaste experiment. The current PC prototype supports reagent selection, mixing in different orders, pouring animations, and foam visualization. Experiment rules are separated from input handling so the simulation can be extended to MR and CAVE interfaces.

    CodeDemo guide

  • Transformer for English-to-Chinese Translation

    Natural language processing · Learning project

    An implementation of the original Transformer encoder-decoder architecture in PyTorch for English-to-Chinese translation. The project covers parallel-corpus preprocessing, model training, and inference, with an experimental notebook and GPU deployment documentation.
