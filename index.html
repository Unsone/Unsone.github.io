💻Projects

扩散模型数据自适应 SNR-Timestep 映射函数研究

PyTorch · DDPM/DDIM · UNet / ViT / DiT 主干

扩散模型训练与采样通常依赖人工设定的固定 SNR-timestep 映射（如线性 / cosine schedule），跨模态迁移时表现不稳定； 提出数据自适应、模态无关的映射函数，并基于该映射设计去噪采样的跳步优化方法。

相比固定 schedule 基线，平均推理耗时降低 60%+，生成精度提升 40%+。

安全约束的自纠错个人工作助理 Agent Harness

Python · Function Calling 架构 · DuckDuckGo Search API

实现运行在个人电脑上的日常工作辅助与自动化 Agent：由 LLM 把任务规划为结构化步骤，在安全规则约束下调用 Shell、 文件编辑、Obsidian 笔记、网页搜索等工具执行，并将执行记录沉淀至本地知识库，形成从任务输入到结果记录的完整闭环。

从零搭建 Agent 控制回路，86 个单元测试全部通过；实现双层自纠错与拒绝/确认/放行三态安全模型，命令执行全程可审计。

基于 Transformer 架构复现的中英机器翻译系统

Python · PyTorch · Transformer Encoder-Decoder · 注意力机制

复现原始 Transformer 论文的 Encoder-Decoder 架构，用于中英双语翻译任务；完成双语平行语料清洗、分词、批处理训练与超参调整。
